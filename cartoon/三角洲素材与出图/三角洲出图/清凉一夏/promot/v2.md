# V2｜统一导演式开放版

V2 对所有角色使用完全相同的 Prompt，只替换角色素材图并填写唯一变量“角色英文名”。具体动作、场景、夏日道具、服装改造、配色和拼贴排版均由模型结合角色自行创作。

## 统一 Prompt

    当前角色英文名：【CHARACTER ENGLISH NAME】

    角色素材图用于确认人物身份、发型、发色、核心装扮和标志性装备；海报样例图仅用于提取系列共同的视觉语言，不复制样例中的人物、构图、姿势、道具或配色。

    以角色素材图中的成年人物为唯一主角，不改变人物的身份与核心识别特征；允许在保持角色辨识度的前提下，自由进行自然、合理的夏日化服装与装备改造。

    参考素材只用于确认角色设定，不沿用其中可能存在的电影写实、真人摄影或粗粝3D质感。无论原素材是什么画风，人物面部都统一表现为精致、柔和、有表现力的半写实动漫漫画脸，呈现类似蝶参考图的脸部质感：五官清秀，眼神生动，皮肤通透，发丝细腻，具有高品质游戏漫画插画的美感；不要真人摄影脸，不要电影写实脸，不要塑料3D脸。

    围绕“清凉一夏”自由创作一张竖版9:16单人角色海报。请结合人物自身的职业、性格、能力和装备，自主设计夏日场景、人物姿态、互动方式、服装变化、清凉物件、主色调和视觉叙事。画面应清爽、有想象力、有角色魅力，并且让不同人物自然形成各自独特的夏日主题。

    整体采用参考海报共同的复古游戏杂志拼贴语言，可以自由运用醒目的角色标题、手写涂鸦、拍立得照片、撕纸、贴纸、印章、能力符号以及纸张油墨质感。不要机械套用固定模板，也不要复刻任何一张样例图的布局，请根据当前角色重新组织画面，让人物始终是最清晰的视觉中心。

    画面左上角或顶部左侧必须设置全画面最醒目的大号英文主标题，标题内容必须逐字、准确、清晰地写成“【CHARACTER ENGLISH NAME】”。不得把夏日主题词、职业名称、中文名或样例海报中的其他人物姓名当作主标题，不得出现任何其他角色名。可以自由设计副标题，但副标题不能替代或遮挡角色英文名。

    高完成度半写实漫画插画，清透夏日光线，丰富空间层次，精致面部与发丝，服装和装备细节清晰，画面活泼但不杂乱，竖版9:16，4K高清。仅出现一个人物，无水印，手部和肢体自然。

## 使用方式

- 每次只更换当前角色的素材图。
- 将【CHARACTER ENGLISH NAME】替换为当前角色的准确英文名；除此之外不改 Prompt 正文。
- 海报样例图只承担系列风格参考作用；若某张样例的角色文字污染当前人物，可减少或替换该样例，但不改 Prompt 正文。
- 不再为任何角色增加专属 Prompt。
